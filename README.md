# Kampus Kayip Esya

Esya kaydi, eslestirme, teslim.

## Calistirma
    javac Uygulama.java
    java Uygulama

(Windows icin calistir.bat, Linux/Mac icin calistir.sh de kullanilabilir. JDK gerekir.)
Ana menude 0 veya q ile cikilir. Ilk soruya 0 girilirse program hicbir sey yapmadan biter.

## Uc ihlal kurali
Teslim alirken esyanin ayirt edici ozelligini ayni kullanici 3 kez yanlis girerse
kullanici 60 saniye gecici olarak engellenir ve nedeni ekrana yazilir.

## Gereksinimler (kilometre tasi eslemesi)
- Dizi alip tek deger donduren metot: toplam(), enBuyuk(), ortalama()
- Girdi dogrulayan metot: sayiOku(), metinOku()
- Gozcu degerle biten dongu: ana menu dongusu (0 / q)
- Calisan ayirt edici kural: gizli ayirt edici ozellik dogrulanmadan esya teslim edilmez
- Ana sinif: Uygulama
